### What I'm working on

- **Voice & AI automation** — telephone agents, realtime audio pipelines, and workflow orchestration for real businesses.
- **Autonomous agent infrastructure** — running long-lived coding agents on remote machines, driven from chat.
- **Product & web** — B2B sites and mobile apps, from landing page to API.
